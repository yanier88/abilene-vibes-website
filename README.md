# Abilene Vibes Website

Independent static landing page for Abilene Vibes.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

This project is intentionally separate from the main Abilene Vibes app repository. It does not integrate Supabase, Stripe, Android, Capacitor, Admin, Cloudflare, DNS, or the abilenevibes.com domain yet.
